## 1. Feature Dictionary

The model utilizes 17 pre-match features structured across market odds, team ratings, rolling form, territorial dominance, and player performance metrics:

| Feature | Category | Description | Formula / Source |
| :--- | :--- | :--- | :--- |
| `p_home` | Market Odds | Implied probability of a Home Win, margin-normalized across 1X2 market. | $(1 / \text{Odds}_H) / \sum (1 / \text{Odds})$ |
| `p_draw` | Market Odds | Implied probability of a Draw, margin-normalized across 1X2 market. | $(1 / \text{Odds}_D) / \sum (1 / \text{Odds})$ |
| `p_away` | Market Odds | Implied probability of an Away Win, margin-normalized across 1X2 market. | $(1 / \text{Odds}_A) / \sum (1 / \text{Odds})$ |
| `elo_diff` | Team Strength | Pre-match Elo rating differential between home and away teams. | $\text{Elo}_{\text{home}} - \text{Elo}_{\text{away}}$ |
| `form_diff` | Recent Form | Differential in points accumulated over the previous 5 matches. | $\text{Points}_{\text{home, last 5}} - \text{Points}_{\text{away, last 5}}$ |
| `goals_form_diff` | Attacking Form | Differential in goals scored over the previous 5 matches. | $\text{GF}_{\text{home, last 5}} - \text{GF}_{\text{away, last 5}}$ |
| `defensive_form_diff` | Defensive Form | Differential in goals conceded over the previous 5 matches (inverted). | $\text{GA}_{\text{away, last 5}} - \text{GA}_{\text{home, last 5}}$ |
| `deep_diff` | Territorial Dominance | Differential in completed passes within 20 meters of the opponent goal. | $\text{Deep}_{\text{home}} - \text{Deep}_{\text{away}}$ |
| `xpts_diff` | Chance Quality | Expected points differential calculated from match expected goals ($xG$). | $\text{xPts}_{\text{home}} - \text{xPts}_{\text{away}}$ |
| `ppda_diff` | Tactical Pressing | Differential in Passes Allowed per Defensive Action in the opponent's defensive 60%. | $\text{PPDA}_{\text{home}} - \text{PPDA}_{\text{away}}$ |
| `sot_diff` | Shot Accuracy | Differential in 5-match rolling average shots on target. | $\text{SoT}_{\text{home, avg}} - \text{SoT}_{\text{away, avg}}$ |
| `home_xg_avg` | Attacking Quality | 5-match rolling average of Expected Goals ($xG$) generated by the home team. | $\frac{1}{5} \sum_{i=1}^5 xG_{\text{home}, i}$ |
| `away_xg_avg` | Attacking Quality | 5-match rolling average of Expected Goals ($xG$) generated by the away team. | $\frac{1}{5} \sum_{i=1}^5 xG_{\text{away}, i}$ |
| `home_xga_avg` | Defensive Quality | 5-match rolling average of Expected Goals Conceded ($xGA$) by the home team. | $\frac{1}{5} \sum_{i=1}^5 xGA_{\text{home}, i}$ |
| `away_xga_avg` | Defensive Quality | 5-match rolling average of Expected Goals Conceded ($xGA$) by the away team. | $\frac{1}{5} \sum_{i=1}^5 xGA_{\text{away}, i}$ |
| `gk_performance_diff` | Goalkeeping Performance | Differential in goalkeeper shot-stopping save percentage and clean sheet frequency. | $\text{GK}_{\text{home score}} - \text{GK}_{\text{away score}}$ |
| `shooting_efficiency_diff` | Finishing Efficiency | Differential in shot accuracy (SoT/Shots) and clinical goal conversion rate (Goals/Shots). | $\text{Shoot}_{\text{home score}} - \text{Shoot}_{\text{away score}}$ |

## 5. Model Architecture & Hyperparameters

The multi-class gradient boosted trees model is parameterized as follows:

```python
XGBClassifier(
    objective="multi:softprob",  # Multi-class calibrated probability output
    num_class=3,                 # Class 0: Home Win, Class 1: Draw, Class 2: Away Win
    n_estimators=500,            # Total sequential boosting iterations
    max_depth=3,                 # Tree depth constraint to prevent overfitting
    learning_rate=0.01,          # Step size shrinkage per boosting step
    subsample=0.8,               # 80% row sampling ratio per tree
    colsample_bytree=0.7,        # 70% feature sub-sampling ratio per tree
    min_child_weight=8,          # Minimum sum of instance weight in leaf node
    reg_alpha=0.8,               # L1 regularization term on weights
    reg_lambda=1.7,              # L2 regularization term on weights
    eval_metric="mlogloss",      # Multiclass logarithmic loss
    random_state=42,
    verbosity=0
)
```
